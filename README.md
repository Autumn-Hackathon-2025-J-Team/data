# Jteam　アプリ概要
タイトル「ゴハンドースル」
「今日なに食べたい？」の案をチャットで出し合う、家族内のチャットアプリです。

家族のリクエストを聞き、メニュー決めに悩む負担を減らすためのアプリで
最終的に料理をする人がなにを作るかを決定して、そのままチャットで家族にお知らせすることができます。

また、追加機能として
これまで決定してきたメニューを見る「ごはん履歴」
メニューが決まらないときにランダム決定する「ごはんルーレット」
食べたいメニュー案にそれぞれが投票する「ごはん投票」を検討しました。


# ゴハンドースル画面説明
<トップ画面>
ログイン または 新規登録（管理者アカウント作成）を選択

<ログイン> 
メールアドレス・パスワードでログイン　

<管理者アカウント作成>
メールアドレス・パスワード・ユーザー名・家族名を登録して
管理者アカウントを作成

<家族アカウント作成>
メールアドレス・パスワード・ユーザー名を登録して
家族アカウントを作成
※管理者ユーザーだけが家族アカウントを作成することができる

<チャット画面>
同じ家族グループのチャットルームが表示される
自分のメッセージは画面右側、相手のメッセージは画面左側に表示される

<ごはん決定>
※管理者ユーザーだけが利用できる機能
最終的に何にするかを決定して、そのままチャットへ送信して家族にお知らせすることができる

<ごはん履歴>
これまで決定してきたメニューの一覧を見ることができる


**ブラウザで確認**
```
http://localhost:55000
```
