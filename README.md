# Jteam　アプリ概要
タイトル「ゴハンドースル」
「今日なに食べたい？」の案をチャットで出し合う、家族内のチャットアプリです。

家族のリクエストを聞き、メニュー決めに悩む負担を減らすためのアプリで
最終的に料理をする人がなにを作るかを決定して、そのままチャットで家族にお知らせすることができます。

また、追加機能として
これまで決定してきたメニューを見る「ごはん履歴」
メニューが決まらないときにランダム決定する「ごはんルーレット」
食べたいメニュー案にそれぞれが投票する「ごはん投票」を検討しました。


# ゴハンドースル画面説明
<トップ画面></br>
ログイン または 新規登録（管理者アカウント作成）を選択</br>

<ログイン> </br>
メールアドレス・パスワードでログイン　</br>

<管理者アカウント作成></br>
メールアドレス・パスワード・ユーザー名・家族名を登録して</br>
管理者アカウントを作成</br>

<家族アカウント作成></br>
メールアドレス・パスワード・ユーザー名を登録して</br>
家族アカウントを作成</br>
※管理者ユーザーだけが家族アカウントを作成することができる</br>

<チャット画面></br>
同じ家族グループのチャットルームが表示される</br>
自分のメッセージは画面右側、相手のメッセージは画面左側に表示される</br>

<ごはん決定></br>
最終的に何にするかを決定して、そのままチャットへ送信して家族にお知らせすることができる</br>
※管理者ユーザーだけが利用できる機能</br>

<ごはん履歴></br>
これまで決定してきたメニューの一覧を見ることができる</br>


**ブラウザで確認**
```
http://localhost:55000
```


### ディレクトリ構成
```

│   ├── app.py
│   ├── models.py

│   ├── Flask
│   │   └── Dockerfile. # Flask(Python)用Dockerファイル
│   └── MySQL
│       ├── Dockerfile  # MySQL用Dockerファイル

```
